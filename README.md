# 你好，我是 Linn（ONLYLOVELYKISS）

**我的本职工作不属于 IT 行业，写代码纯粹是个人爱好。** 我喜欢把遇到的小问题拆开研究，试着做成自己能用的工具；也会记录学习过程、保存资料，偶尔搭个网站整理喜欢的东西。这里的项目来自日常需求和好奇心，做得不快，就慢慢迭代。

[个人主页：wwhooo.com](https://wwhooo.com) · [浏览所有仓库](https://github.com/ONLYLOVELYKISS?tab=repositories)

## 我喜欢做的事

- **把问题做成小工具**：从 Excel 工资表处理，到下载和日常自动化，先解决一个具体需求。
- **边学边做**：写过 Python 课程练习，也会尝试 AI、互联网和不同平台上的小点子。
- **整理自己的空间**：用个人网站收纳项目、常用入口、摄影和记录；用自动化收集值得继续了解的开源项目。
- **留下过程**：有些仓库是正在使用的工具，有些只是阶段性练习或资料归档，README 会尽量说明它们各自的来历。
